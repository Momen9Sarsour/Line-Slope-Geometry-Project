# Line & Slope Geometry Project – Java

A Java console application that works with 2D points to calculate lines, slopes, special points, and perform geometric operations.

---

## 🚀 Features

### 📌 1. Display Points  
Shows all stored points in (x, y) format.

### 📌 2. Shuffle Points  
Randomly rearranges the order of all points.

### 📌 3. Display Line Equation  
Given two points, the program calculates and prints the line equation: y = mx + b


### 📌 4. Right-Most Lowest Point  
Finds the point that is:
- Farther to the right  
- And lowest on the plane

### 📌 5. Display Slopes  
Calculates slope values between multiple point pairs.

### 📌 6. Quit  
Exits the program.
